Factory Inventory Management System

A Vue 3 single-page app talking to a FastAPI backend that serves in-memory mock data loaded from JSON files. There is no database, no authentication, and no persistence across restarts.

System architecture

Two processes on localhost. The browser loads the SPA from Vite and calls the API directly over CORS. Nothing proxies between them.

Tech stack

Small dependency surface on both sides. No build-time type checking, linting, or frontend tests are configured.

Data flow: changing a filter

This is the main interaction in the app. All four filters go through the same path.

  1. User picks a filter in FilterBar.vueTime period, warehouse, category, or order status.
  2. Shared state updates in useFilters.jsThe refs live at module level, so every view reads the same values.
  3. The view re-fetchesIt calls getCurrentFilters() and passes the result to methods in api.js.
  4. api.js builds the requestValues of 'all' are dropped, e.g. GET /api/orders?warehouse=Tokyo&month=Q2-2025.
  5. FastAPI filters the in-memory listapply_filters() does exact matching (case-insensitive for category and status). filter_by_month() does a substring match on order_date, and quarters are expanded via QUARTER_MAP.
  6. Pydantic validates the responseRoutes declare response_model, so the JSON has to match the model shape.
  7. Vue recomputesRaw responses go into refs. Totals, chart series, and tables are computed properties.

Known gaps

Found while reading the code.

Missing backend routes. api.js calls /api/tasks (GET/POST/PATCH/DELETE) and /api/purchase-orders, but main.py has no handlers for them, so those requests return 404.
Page not reachable. views/Backlog.vue exists but isn't registered in the router.
Quarters only cover 2025. QUARTER_MAP only knows Q1–Q4 2025.
Auth is mocked. useAuth.js returns a hardcoded user, and CORS allows every origin.
Tests pass. 40 backend tests pass when run from server/: uv run pytest -c ../tests/pytest.ini ../tests
